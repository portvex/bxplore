bxplore is a viewer and editor for executable files. It shows every structure of a PE, ELF or Mach-O file as a tree of editable tables, next to a hex editor and a disassembler, and it rebuilds imports, exports, resources, sections, relocations and signatures.

Screens

One window. Every structure.

PE, ELF and Mach-O files, shown in both the dark and the light theme.

Features

A complete toolkit for every format

Each header is shown as Member, Offset, Size, Value and Meaning. To change a value, double-click it.

Structure tree

Every header, directory and table in one tree, with icons by kind and a row filter in every table.

Edit in place

Flag and enum fields get check boxes and drop-downs. Undo with Ctrl/Cmd+Z, and export your changes as a patch list or a Python script.

Hex editor

Linked to the selection, with typing, go to offset, and hex or text search. "Structure" jumps to whatever covers the cursor.

Disassembler

x86, x64, ARM and ARM64, with import names and strings as comments, a function list, and double-click to follow calls.

Compare

Diff against another file or another open tab: a structure-level comparison plus a byte summary.

Signatures, verified

Authenticode is checked cryptographically (RSA and ECDSA, chains, timestamps), and every Mach-O code page hash is verified.

Search & navigate

Search every structure. Follow a value as an RVA, VA or file offset, and go Back and Forward through your history.

Tools built in

An address converter, a strings view (ASCII and UTF-16), MD5, SHA-1 and SHA-256 hashes, entropy, imphash, and bookmarks with notes.

Formats

It rebuilds the file, too

bxplore rewrites the tables that other tools only display, and it writes a valid file back.

PE

Windows & .NET

View

  • DOS, Rich, NT and optional headers, data directories, and sections with entropy
  • Export, import, delay import, resources, exception, TLS, load config, debug and overlay
  • .NET metadata tables, signatures, and an IL disassembler
  • Authenticode, including nested signatures and RFC 3161 timestamps

Edit

  • Add, delete or dump sections
  • Add and rename imports; unbind; convert delay imports
  • Add, rename, delete or forward exports
  • Preview, replace or add resources (icons, version info, manifests)
  • Edit relocations and TLS callbacks; recompute CheckSum and SizeOfImage
ELF

Linux & Unix

View

  • Header, program headers and section headers
  • Dynamic section, symbol tables, relocations, and notes (build id)
  • Symbol versioning, needed and defined versions
  • GNU hash table, with every chain entry checked

Edit

  • Add, rename or remove needed libraries
  • Set or remove SONAME, RPATH and RUNPATH
  • Move the tables to a new PT_LOAD segment when they no longer fit
  • Add, remove or dump sections
Mach-O

macOS & iOS

View

  • Fat header, mach header, load commands, segments, and symbols
  • Exports trie, bind and rebase opcodes, and chained fixups
  • Objective-C classes and methods, and Swift types
  • Code signature: CDHash, entitlements, and a check of every page hash

Edit

  • Add, change or remove library load commands
  • Edit run paths in every architecture
  • Remove the code signature command

Install

Get bxplore

Packages for x86_64 and ARM64. Pick yours below, or browse the releases page (with SHA256SUMS).

Download the NSIS installer (-setup.exe) or the portable zip, which holds only bxplore.exe. The installer adds "Open with bxplore" to Explorer's right-click menu.

Go to the latest release

Download the universal DMG, which runs on both Intel and Apple Silicon, or install with Homebrew.

Go to the latest release
brew install --cask portvex/tap/bxplore

bxplore is not notarized. Open the app the first time with right-click → Open, or run:

xattr -dr com.apple.quarantine /Applications/bxplore.app

Releases include a standalone executable (also as .tar.gz) and a Flatpak, each for x86_64 and aarch64.

Go to the latest release
flatpak install --user ./bxplore-*-linux-x86_64.flatpak

The flake builds for x86_64-linux and aarch64-linux.

nix run github:portvex/bxplore
nix profile install github:portvex/bxplore

You need Rust and a C compiler (Capstone is built from source). On Linux, you also need the GTK 3 development packages.

cargo build --release
./target/release/bxplore [file]
./target/release/bxplore --dump <file>
